## TL;DR

- **Reality почти ничего не ест.** Один Go-бинарник `xray`. Хватает **256–512 МБ RAM,
  1 vCPU**. Диск — 5–10 ГБ за глаза. Домен и сертификат **не нужны** (в этом весь смысл Reality).
- **Главный дефицитный ресурс — не RAM, а трафик и чистый IP.** Бери тариф, где
  включено хотя бы **1–2 ТБ/мес** и IP не в блэклистах.
- **Лучшая цена/качество прямо сейчас — RackNerd** (~$11–12/год за 1 ГБ, цена
  зафиксирована на весь срок). **Если нужна оплата криптой/анонимно — Aeza**.

## Минимальные требования под VLESS Reality

| Ресурс          | Минимум      | Комфортно     | Комментарий |
| --------------- | ------------ | ------------- | ----------- |
| RAM             | 256 МБ       | 512 МБ – 1 ГБ | `xray` в простое ест ~20–40 МБ |
| vCPU            | 1            | 1             | шифрование в userspace, нагрузка низкая |

Порт 443 наружу — обязателен (Reality маскируется под TLS к реальному SNI).

- **Меньше всего проблем с шейпингом сейчас:** Финляндия, Швеция, Австрия,
  Нидерланды (Амстердам иногда пошейплен — тестируй), Германия (Франкфурт — популярно,
  местами душат).
- **Хороший пинг + запас:** восточное побережье США (Нью-Йорк, Шарлотт) — дальше,
  но часто стабильнее «затёртых» EU-точек.
- **Азия:** Сингапур/Япония — если гоняешь трафик в ту сторону.
- **Правило:** для Reality важнее **стабильность и «свежесть» IP-подсети**, чем
  географическая близость. Один задушенный дата-центр рядом хуже чистого подальше.

## Как не влететь (короткий чек-лист перед оплатой)

- [ ] **Проверь IP на блэклисты** после покупки (или спроси в тикете подсеть заранее).
      «Грязный» IP = капчи, баны, плохой роутинг.
- [ ] **KVM предпочтительнее OpenVZ**, но для Reality сервера OpenVZ тоже работает
      (TUN/kernel-модули на сервере не нужны).
- [ ] **Смотри лимит трафика**, а не только RAM. VPN упирается в трафик первым.
- [ ] **Промокоды меняются** — гугли «<провайдер> promo code <месяц/год>» перед оплатой.
- [ ] **Бэкап конфига** (`config.json` + приватный ключ Reality) храни локально —
      если VPS «уедет», развернёшь за 2 минуты на новом.
- [ ] **Не бери откровенный неизвестный «$1 VPS»** без отзывов на LowEndTalk — риск,
      что провайдер исчезнет вместе с деньгами.

## Что дальше (быстрый путь к рабочему VLESS Reality)

1. Debian 12 / Ubuntu 22.04, обнови систему.
2. Поставь `xray-core` (официальный установщик или бинарник с GitHub Xray).
3. Сгенерь UUID и пару ключей Reality (`xray x25519`), выбери «донор» SNI
   (реальный крупный сайт на 443, напр. чужой стабильный TLS-хост).
4. Пропиши inbound VLESS + Reality на 443, отдай клиенту (v2rayN / v2rayNG / Nekoray).
5. Открой 443 в файрволе провайдера.
